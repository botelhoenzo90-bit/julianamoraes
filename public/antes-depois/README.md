# Galeria de antes e depois

Coloque nesta pasta as fotos reais dos resultados, mantendo estes nomes para que apareçam automaticamente no site:

- `caso-1-antes.jpg`
- `caso-1-depois.jpg`
- `caso-2-antes.jpg`
- `caso-2-depois.jpg`
- `caso-3-antes.jpg`
- `caso-3-depois.jpg`

As imagens devem ser JPG ou, se preferir outro formato, atualize também a extensão no arquivo `src/routes/index.tsx`. Prefira imagens com enquadramento e iluminação semelhantes para facilitar a comparação. Publique apenas imagens autorizadas pela pessoa retratada e com consentimento para uso.

Enquanto as fotos não forem adicionadas, a seção exibirá espaços reservados no lugar das imagens.
