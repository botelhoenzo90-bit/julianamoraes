# Imagens do carrossel de procedimentos

Esta pasta está reservada para as imagens locais do carrossel. Use os nomes `foto-01.webp` até `foto-20.webp`, na mesma ordem dos procedimentos exibidos no site.

No momento, o carrossel utiliza as imagens fornecidas no endereço `julianamoraes.netlify.app` para manter as fotos visíveis enquanto os arquivos locais são adicionados.
